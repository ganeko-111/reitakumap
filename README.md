# 麗澤マッピング

## 概要

麗澤大学周辺の地図に、付箋のような短いメモを貼れるプロトタイプです。地図をクリックするとその場所にメモを追加でき、追加した付箋は自分のブラウザの `localStorage` に保存されます。

## ファイル構成

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## 使い方

ブラウザで `index.html` を開きます。

1. 地図上の好きな場所をクリックします。
2. 表示された付箋に短いメモを書きます。
3. 付箋の種類を「発見」「おすすめ」「注意」「休憩」から選びます。
4. 必要なら写真を1枚選びます。写真は小さく圧縮されて保存されます。
5. 「保存」を押すと、種類ごとの色で付箋が追加されます。
6. 地図を引くと、付箋は小さい付箋アイコンや丸印に切り替わります。
7. 付箋をドラッグすると、好きな場所へ移動できます。
8. 移動後の位置は自動で保存されます。
9. 付箋をクリックすると内容・種類・写真を確認できます。
10. 「編集」を押すと、内容・種類・写真を変更できます。
11. 編集フォームで「保存」を押すと、付箋と保存データが更新されます。
12. 「削除」を押すと付箋を削除できます。
13. 「閉じる」を押すと、付箋の表示を閉じます。
14. 「リセット」を押して確認すると、保存済みの付箋をすべて削除できます。
15. 左上パネルの「隠す」を押すと小さな「i」ボタンになり、もう一度押すと再表示できます。

## GitHub Pagesでの公開

このプロジェクトは静的なHTML/CSS/JavaScriptだけで動くため、GitHub Pagesで公開できます。リポジトリに4ファイルを置き、GitHub Pagesの公開元を設定するとURLで共有できます。
