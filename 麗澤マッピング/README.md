# 麗澤マッピング

## 概要

麗澤大学周辺の地図に、付箋のような短いメモを貼れるプロトタイプです。地図をクリックするとその場所にメモを追加でき、追加した付箋は自分のブラウザの `localStorage` に保存されます。

## ファイル構成

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## 使い方

ブラウザで `index.html` を開きます。

1. 地図上の好きな場所をクリックします。
2. 表示された付箋に短いメモを書きます。
3. 「保存」を押すと、地図上に付箋が追加されます。
4. 付箋をドラッグすると、好きな場所へ移動できます。
5. 移動後の位置は自動で保存されます。
6. 付箋をクリックすると内容を確認できます。
7. 「編集」を押すと、内容を変更できます。
8. 編集フォームで「保存」を押すと、付箋と保存データが更新されます。
9. 「削除」を押すと付箋を削除できます。
10. 「閉じる」を押すと、付箋の表示を閉じます。

## GitHub Pagesでの公開

このプロジェクトは静的なHTML/CSS/JavaScriptだけで動くため、GitHub Pagesで公開できます。リポジトリに4ファイルを置き、GitHub Pagesの公開元を設定するとURLで共有できます。
